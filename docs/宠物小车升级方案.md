### 2.2 OLED 屏幕详细选型

推荐型号：**0.96寸 128×64 OLED (SSD1306)**

```
推荐接线方式：使用现有 I2C 总线 (SDA/SCL)，无需额外引脚！

引脚分配：
┌──────────────────────┐
│  OLED (SSD1306)       │
│  VCC  ──→ 树莓派 3.3V │
│  GND  ──→ 树莓派 GND  │
│  SDA  ──→ SDA1 (Pin3) │  ← 与驱动板共享 I2C
│  SCL  ──→ SCL1 (Pin5) │
└──────────────────────┘

I2C 地址：0x3C 或 0x3D (可通过硬件跳线选择)
PCA9685 地址：0x60
两者地址不冲突，可直接挂载！
```

**为什么选 I2C 而不是 SPI？**
- 现有 I2C 总线已启用，无需额外布线
- 只需 2 根线 (SDA/SCL) + 电源
- PCA9685 (0x60) 和 SSD1306 (0x3C) 地址不冲突
- 树莓派 I2C 总线最多可挂 127 个设备

### 3.5 情感引擎设计

```python
# mood_engine.py

from enum import Enum
from dataclasses import dataclass
import time

class Emotion(Enum):
    NEUTRAL = "neutral"
    HAPPY = "happy"
    SAD = "sad"
    ANGRY = "angry"
    SURPRISED = "surprised"
    SLEEPY = "sleepy"
    LOVE = "love"
    THINKING = "thinking"
    SCARED = "scared"

@dataclass
class MoodState:
    """情感状态机"""
    primary: Emotion = Emotion.NEUTRAL
    intensity: float = 0.5          # 情绪强度 [0, 1]
    valence: float = 0.0             # 正负性 [-1, 1]
    arousal: float = 0.5             # 唤醒度 [0, 1]
    last_update: float = 0.0
    decay_rate: float = 0.02        # 情绪衰减速度 / tick

class MoodEngine:
    """情感引擎 - 管理宠物的情绪状态"""
    
    def update(self, emotion: Emotion, intensity: float = 1.0):
        """被触发时更新情绪"""
    
    def decay(self, delta_time: float):
        """情绪随时间自然衰减"""
    
    def random_mood_behavior(self):
        """空闲时随机情绪行为 (打哈欠、眨眼、哼歌等)"""
    
    def get_current_emotion(self) -> Emotion:
        """获取当前主情绪"""
```

## 四、学生编程接口（关键设计）

### 4.1 为什么需要这个？

这是整个方案的**核心教育价值**：让学生不仅能跑现成的大模型，还能**自己写代码控制表情**，理解硬件→驱动→API→应用的完整链路。

### 4.2 学生编程接口 - emoji_robot.py

```python

    def backward(self):
    def leftSlide(self):
    def rightSlide(self):
    def turnLeft(self):
    def turnRight(self):
    def spin(self):

    def look_down(self, delta=5):
```

```python
    "name": "happy",
    "rows": [
        # 每行 128 bit = 16 字节
```

```python
from luma.core.interface.serial import i2c
from luma.oled.device import ssd1306
from PIL import Image, ImageDraw, ImageFont
import time

class OLEDDriver:
    """OLED 128×64 屏幕驱动"""
    
    def __init__(self, address=0x3C):
        serial = i2c(port=1, address=address)
        self.device = ssd1306(serial)
        self.width = 128
        self.height = 64
        self.image = Image.new('1', (self.width, self.height))
        self.draw = ImageDraw.Draw(self.image)
        self.font = ImageFont.load_default()
    
    def clear(self):
        self.draw.rectangle([0, 0, self.width, self.height], fill=0)
    
    def render_face(self, face_data: dict):
        """根据预定义 face 数据绘制表情"""
        self.clear()
        
        # 绘制左眼 (圆形或特殊形状)
        self._draw_eye(face_data.get("left_eye", "circle"), x=30, y=28)
        # 绘制右眼
        self._draw_eye(face_data.get("right_eye", "circle"), x=80, y=28)
        # 绘制嘴巴
        self._draw_mouth(face_data.get("mouth", "line"))
        
        self.device.display(self.image)
    
    def draw_text(self, text: str, y: int = 52):
```

### 8.2 风险与规避

| 风险 | 影响 | 规避方案 |
|------|------|----------|
| 树莓派 4B 运行本地 LLM 太慢 (5-10s/轮) | 用户体验差 | 降级到云端 API (豆包/通义) 加速 |
| USB 麦克风兼容性问题 | 语音采集失败 | 提前测试，优先选 ReSpeaker |
| OLED 地址冲突 | 屏幕不显示 | 用 `i2cdetect -y 1` 扫地址，0x3C/0x3D 都可用 |
| pyttsx3 在中文环境下语音生硬 | 体验差 | 换 espeak 或云端 TTS (火山引擎 TTS) |
| 树莓派 2GB 内存不足 | LLM + 摄像头 + Flask 同开 OOM | 1) 关摄像头 2) 用更小模型 qwen2.5:0.5b 3) swap 扩内存 |

## 一、安全须知

使用前请务必确认：

1. **急停位置**：中控面板「运动控制」卡片标题行右侧有红色**急停**按钮。任何异常先按急停。
2. **首次测试架空**：第一次上电或改过程序后，把车体架空（轮子离地），确认四个轮子转向正确、云台不撞限位，再放到地面。
3. **不要堵转**：轮子被卡住时不要长时间给速度，电机和驱动板会发热。
4. **不要手掰云台**：舵机通电时强行掰动会扫齿；需要调整角度请用面板按钮。
5. **电池**：电量不足时会出现“电机无力、树莓派重启、WiFi 掉线”，先充电再排查软件。
6. **USB 供电**：树莓派请使用 5V/3A 电源，供电不足会导致摄像头掉线、系统卡死。
7. **桌面清理**：小车运动前移开水杯、纸张、线缆，避免卷入轮子。
8. **激光/强光**：不要用强光直射摄像头，会影响颜色识别和追踪。

## 二、第一次使用：检查清单

### 2.1 硬件连接

| 部件 | 接到哪里 | 检查方法 |
|---|---|---|
| PCA9685 驱动板 | 树莓派 I2C（SDA/SCL/5V/GND） | `i2cdetect -y 1` 能看到 `60` |
| 四个电机 | PCA9685 通道 1/2/3/4 | 通道与轮子位置对应见下表 |
| 水平舵机 | PCA9685 通道 0 | 上电应回到 90° |
| 垂直舵机 | PCA9685 通道 1 | 上电应回到 90° |
| OLED 屏幕 | I2C（与 PCA9685 并联） | `i2cdetect -y 1` 能看到 `3c` |
| USB 摄像头 | 树莓派 USB 口 | `ls /dev/video*` 有 `video0` |
| USB 麦克风/音箱 | 树莓派 USB 口 | `arecord -l` / `aplay -l` 能看到设备 |

电机通道与轮位对应（从车头看）：

| 通道 | 轮子 |
|---|---|
| 1 | 右前 FR |
| 2 | 左前 FL |
| 3 | 左后 TL |
| 4 | 右后 TR |

### 2.2 软件检查

在树莓派终端执行：

```bash
i2cdetect -y 1                 # 应看到 60 和 3c
python3 -c "import cv2; print(cv2.__version__)"
python3 -c "import flask; print(flask.__version__)"
```

I2C 未开启时：

```bash
sudo raspi-config
# Interface Options → I2C → Yes → 重启
```

### 2.3 网络

- 小车和电脑/手机连**同一个 WiFi**；
- 默认地址为 `192.168.0.100`，以启动脚本打印的地址为准；
- 板端查 IP：`hostname -I`。

## 三、开机与启动

### 3.1 推荐：Windows 一键启动

在开发机 `e:\work\AITank` 目录：

```powershell
python run_petcar.py            # 启动并打印访问地址
python run_petcar.py --restart  # 重启
python run_petcar.py --full     # 加载真实语音链路（whisper，启动较慢）
python run_petcar.py --push     # 先把最新代码推到板上，再启动
python run_petcar.py --logs     # 查看最近 40 行日志
python run_petcar.py --stop     # 停止板上程序
```

也可以双击 `run_petcar.bat`。

启动成功会看到：

```
[OK] 已启动 → http://192.168.0.100:5000/
     积木编程 → http://192.168.0.100:5000/blocks
```

板子 IP 不是 `192.168.0.100` 时：

```powershell
$env:PETCAR_HOST="192.168.0.101"
python run_petcar.py --restart
```

### 3.2 SSH 登录板子启动（推荐：start.sh）

脚本位于 `petcar/start.sh`，已在仓库内。首次使用先加执行权限：

```bash
cd ~/AITank
chmod +x petcar/start.sh
```

日常使用：

```bash
./petcar/start.sh                    # 启动（默认快速模式：面板 + TTS，ASR 走 mock）
./petcar/start.sh --voice            # 启动并开启真实语音对话（whisper base）
./petcar/start.sh --voice --offline  # 语音 + 本地 Piper 离线童声
./petcar/start.sh --rules            # 不调用大模型，只走本地指令规则
./petcar/start.sh --port 5001        # 指定端口

./petcar/start.sh status             # 查看 PID、端口、HTTP 状态
./petcar/start.sh logs               # 最近 80 行日志
./petcar/start.sh logs -f            # 实时跟踪日志
./petcar/start.sh restart            # 重启
./petcar/start.sh stop               # 停止
./petcar/start.sh foreground         # 前台运行，调试用
```

> **重要：面板配置优先于 start.sh**
> 面板点「保存并生效」会写入 `data/config_local.json`，启动时它会覆盖 start.sh 的环境变量。例如里面保存了 `asr_mode=whisper`，默认启动也会加载 whisper；保存了 `llm_backend=ollama`，`--rules` 不会生效。
> 想让 start.sh 的模式生效：在面板点「恢复默认」，或删除 `data/config_local.json`，然后重启。详见 [进程与启动控制](./进程与启动控制.md)。

脚本行为：

- 自动 `cd` 到仓库根目录，日志写到 `petcar/logs/petcar.log`，PID 写到 `petcar/logs/petcar.pid`；
- 用 `setsid` 脱离 SSH 会话，**退出 SSH 后进程继续运行**；
- 启动后自动等待 Web 就绪并打印访问地址；
- 重复执行 `start` 不会启动第二个实例；
- `python run_petcar.py --push` / `python deploy_petcar.py push` 推送代码时会自动给 `*.sh` 加执行权限。

> 如果忘记 `chmod`，也可以直接用 `bash petcar/start.sh` 运行。

**不使用脚本时的等效命令**：

```bash
cd ~/AITank

# 日常：只开 Web 面板（语音识别用 mock，语音合成正常）
PETCAR_ASR_MODE=mock setsid python3 -m petcar.main --flask --port 5000 \
  > ~/AITank/petcar/logs/petcar.log 2>&1 < /dev/null &

# 完整：语音 + 面板
setsid python3 -m petcar.main --flask --port 5000 \
  > ~/AITank/petcar/logs/petcar.log 2>&1 < /dev/null &

# 停止 / 看日志
pkill -f 'petcar.main'
tail -f ~/AITank/petcar/logs/petcar.log
```

其他模式：

| 命令 | 用途 |
|---|---|
| `python3 -m petcar.main` | 语音 + 面板 |
| `python3 -m petcar.main --flask` | 只开面板 |
| `python3 -m petcar.main --voice` | 只开语音 |
| `python3 -m petcar.main --test-emotion` | 轮播 12 种表情，检查屏幕 |

### 3.3 启动成功的标志

1. OLED 显示开心表情，气泡显示“我是小强~”；
2. 喇叭播报欢迎语：“你好，我是小强，是你的编程伙伴……”；
3. 浏览器能打开 `http://<板子IP>:5000/`；
4. 面板「状态」卡片开始显示 CPU、内存、温度。

> 欢迎语每次启动都会播报一次（异步，不阻塞启动）。如果没声音，见[故障排查](#九故障排查)。

### 3.4 停止

```powershell
python run_petcar.py --stop
```

或板端 `pkill -f 'petcar.main'`。正常退出会自动停电机、关摄像头、释放 OLED。

> 同一时间只能跑一个 petcar 进程，否则 5000 端口被占用。

## 四、中控面板操作

打开 `http://<板子IP>:5000/`，建议使用 Chrome / Edge。

### 4.1 实时视频

| 操作 | 说明 |
|---|---|
| 视频区域 | MJPEG 实时画面，上限 15 FPS |
| 关闭摄像头 / 打开摄像头 | 暂时关闭可降低 CPU 占用 |
| 拍照 | 保存一张照片，可在「技能调试」或 API 中获取最新照片路径 |

视频上没有框，说明「对象识别」里对应项没点亮。

### 4.2 运动控制

**底盘九宫格**（中间 ■ 是停止）：

```
↖   ↑   ↗
←   ■   →
↺   ↓   ↻
```

| 按钮 | 动作 |
|---|---|
| ↑ | 前进 |
| ↓ | 后退 |
| ← / → | 左移 / 右移（麦轮横移） |
| ↖ / ↗ | 左前 / 右前斜行 |
| ↺ / ↻ | 左转 / 右转 |
| ■ | 停止 |

| 控件 | 范围 | 说明 |
|---|---|---|
| 速度 | 30~255，默认 150 | 建议课堂用 100~150 |
| 时长 | 0.2~10 s，默认 1 s | 点方向后按此时长自动停 |

**云台**：↑↓←→ 控制，⊙ 回正；`Δ` 为每次转动角度（1~45°，默认 10°）。

**角度显示**：`云台H` 水平角、`云台V` 垂直角、`指令` 当前底盘指令。

**宠物动作**：12 个组合动作按钮，点击后底盘 + 云台自动表演。

| 动作 | 效果 | 动作 | 效果 |
|---|---|---|---|
| 点头 | 上下点头 | 转圈 | 云台+底盘转 360° |
| 摇头 | 左右摇头 | 蹭蹭 | 前进+云台左右蹭 |
| 歪头 | 歪头思考 | 蹦跳 | 前后小跳 |
| 摆尾 | 左右横移+云台摆 | 委屈低头 | 低头后退 |
| 扭腰 | 底盘交替扭动 | 好奇凑近 | 前倾看前方 |
| 左顾右盼 | 云台左右张望 | 伸懒腰 | 抬头+后退 |

> 动作执行中再点手动方向，会自动中断当前动作。积木程序运行时，手动接口会返回 409。

### 4.3 状态

显示心情（愉悦 V / 唤醒 A / 强度 I）、CPU、内存、温度、当前配置徽章，以及 12 个表情快捷按钮。

> 心情会随对话内容变化，并随时间衰减回中性。温度超过 80°C 建议停机散热。

### 4.4 P1 颜色识别

1. 点一个预设色块：红、橙、黄、绿、青、蓝、紫；
2. 或拖动 H/S/V 色条圆点自定义范围（红色支持跨 0° 双段）；
3. 点「启动」在视频中框出该颜色；再点一次停止。

该组 HSV 参数同时作为 **P2 颜色追踪** 和 **积木“如果看到颜色”** 的判定源。

### 4.5 P2 PID 云台追踪

1. 选目标：**人脸** / **颜色积木** / **网球**；
2. 调 `Kp`（0~0.3，默认 0.14，步长 0.005）：越大跟得越快，过大容易来回摆；
3. 点「开始追踪」，云台自动把目标拉到画面中心；
4. 状态栏显示：目标是否可见、像素误差、本帧输出角度。

> `Ki`、`Kd` 当前锁定不参与计算，属正常现象（当前为绝对角度伺服）。

### 4.6 P3 对象识别

复选框点亮即在视频中画框：

| 选项 | 说明 |
|---|---|
| 人 / 宠物 / 水杯 / 球 / 屏幕 | COCO 模型检测，需要 TFLite 模型 |
| 网球·色 | 纯颜色+形状识别，无需模型，响应快 |
| 运动 | 画面变化检测 |
| 颜色 | 使用 P1 的 HSV 参数 |
| 手势识别 | MediaPipe 或 OpenCV 凸包，框上显示手势英文名 |
| 人脸 | YuNet/Haar 人脸框 |

> 同时开太多项会明显降帧，课堂建议一次只开 1~2 项。

### 4.7 对话 / 语音

| 区域 | 用法 |
|---|---|
| 打字聊天 | 输入内容回车或点「发送」，小车会回复并朗读 |
| 让它听你说 | 点「🎙 开始听」→ 对麦克风说一句 → 识别文字自动填进输入框 |
| 让它说给你听 | 输入文字点「朗读」，测试音量、音色、语速 |
| 语音自检 | 点「开始自检」，自动完成“提示音 → 录音 → 识别 → 回复”，并显示峰值/阈值/录音时长，用于现场排查麦克风 |

### 4.8 日志与技能调试

- **日志**：最近 50 条事件，出问题先看这里；
- **技能调试**：按钮由已注册技能自动生成，点「▶ 运行」可直接测试单个功能（移动、云台、拍照、天气、闹钟、表情、宠物动作）。

### 4.9 面板设置

点右上角「⚙️ 设置」：

| 分组 | 可改内容 | 生效方式 |
|---|---|---|
| 身份 | 名字、人格、欢迎语 | 名字/人格立即生效，欢迎语下次启动 |
| 大模型 | 后端（ollama/doubao/mock）、Ollama 地址与模型、豆包 Key 与模型、温度、生成长度、超时 | 保存后重建后端 |
| 语音 | TTS 模式/音色/音调/播放设备、Piper 变调、Edge 超时、ASR 设备、VAD 参数 | 保存后热生效 |

「保存并生效」写入 `data/config_local.json`；「恢复默认」清空本地覆盖。需要重启的项，面板会提示。

## 五、语音交互

### 5.1 怎么说话

- 当前为**常听模式**，不需要唤醒词，直接说即可；
- 距离麦克风 **30~80 cm**，正常音量，不要喊；
- 说完停顿约 1 秒，小车检测到静音后开始识别；
- 环境噪声大时，识别率会下降；可把小车移到安静处。

### 5.2 固定指令（不经过大模型，最快最稳）

| 你说 | 小车动作 |
|---|---|
| 前进 / 往前走 | 前进 2 秒 |
| 后退 / 往后退 | 后退 2 秒 |
| 左转 / 向右转 | 左转 / 右转 2 秒 |
| 转个圈 / 旋转 | 原地转 3 秒 |
| 停下 / 停止 / 别动 | 立即停车 |
| 抬头 / 向上看 | 云台向上 15° |
| 低头 / 向下看 | 云台向下 15° |
| 向左看 / 看左边 | 云台向左 15° |
| 向右看 / 看右边 | 云台向右 15° |
| 点头 | 执行“点头”动作 |
| 摇头 | 执行“摇头”动作 |
| 歪头 | 执行“歪头”动作 |
| 拍照 | 拍一张照片 |

> 这些指令走本地规则，断网、模型未加载时也能用。

### 5.3 自由对话

其他问题交给大模型，例如：

- “你叫什么名字？”
- “今天天气怎么样？”（会调用天气技能，需要联网）
- “10 分钟后提醒我下课”（会设置闹钟）
- “给我讲个笑话”
- “你现在开心吗？”

回答会同时显示在 OLED 表情和面板对话区，并从喇叭播出。

### 5.4 语音自检怎么看

面板点「开始自检」后，结果包含：

| 字段 | 正常表现 | 异常含义 |
|---|---|---|
| 峰值 | 0.05~0.9 | 接近 0：麦克风没声音或设备选错 |
| 阈值 | 0.005~0.08 | 异常高：环境太吵或喇叭回声 |
| 录音时长 | 1~5 s | 0 s：完全没拾到声音 |
| 识别文本 | 与你说的接近 | 空：音量低/语速太快/模型问题 |
| 回复 | 正常中文 | 报错：看日志 |

### 5.5 声音输出

- 默认输出到 **USB 音箱**；没有 USB 音箱时自动尝试 3.5 mm 耳机口；
- 树莓派默认可能走 HDMI，若 HDMI 没接屏幕就没声音；
- 板端切换：

```bash
sudo raspi-config
# System Options → Audio → 选择 Headphones 或 USB Audio
```

- 音量：`alsamixer` → F6 选声卡 → 调 PCM/Playback；
- 临时指定设备：

```bash
PETCAR_TTS_DEVICE=plughw:CARD=UACDemoV10,DEV=0 python3 -m petcar.main
```

## 六、积木编程

打开 `http://<板子IP>:5000/blocks`。

### 6.1 界面

| 区域 | 用途 |
|---|---|
| 左侧工具箱 | 按分类拖出积木 |
| 中间画布 | 拼装程序 |
| 右上按钮 | 运行 / 停止 / 急停 |
| 底部控制台 | 运行日志、当前执行积木高亮 |

快捷键：`Ctrl+Enter` 运行，`Esc` 停止。

### 6.2 积木速查

| 分类 | 积木 | 参数 | 说明 |
|---|---|---|---|
| 事件 | 当程序开始 | 无 | 每个程序必须有且只有一个 |
| 运动 | 向…以速度…移动…秒 | 方向、速度 50~255、时间 0.1~30 s | 到时自动停 |
| 运动 | 停止运动 | 无 | 立即停底盘 |
| 云台 | 云台向…转动…度 | 方向、角度 1~45° | 向上/下/左/右/回正 |
| 表情 | 显示表情… | 12 种 | OLED 表情 |
| 说话 | 说… | 文本 | 调用 TTS 朗读 |
| 识别 | 拍一张照片 | 无 | 保存到小车 |
| 识别 | 如果看到…那么… | 人脸/网球/颜色 | 看到目标才执行内部积木 |
| 控制 | 等待…秒 | 0~600 s | 延时 |
| 控制 | 重复…次… | 1~100 次 | 循环 |
| 控制 | 一直重复… | 无 | 直到点停止 |

### 6.3 三个入门示例

**示例 1：走正方形**

```
当程序开始
  重复 4 次
    向 前进 以速度 150 移动 1 秒
    向 右转 以速度 150 移动 1 秒
  停止运动
```

**示例 2：看到人脸就打招呼**

```
当程序开始
  一直重复
    如果看到 人脸 那么
      显示表情 开心
      说 你好呀，我是小强
    等待 1 秒
```

**示例 3：巡逻 + 拍照**

```
当程序开始
  重复 3 次
    向 左转 以速度 120 移动 0.8 秒
    拍一张照片
    等待 0.5 秒
  停止运动
```

### 6.4 运行规则

1. **同一时间只能运行一个程序**，重复点运行会提示“已有程序在运行”（HTTP 409）；
2. 程序运行期间，中控面板的手动运动/云台会被拒绝，避免抢控制权；
3. 运动类积木有 **0.6 秒运动租约 + 看门狗**：页面卡死、断网、浏览器关闭会在 0.6 秒内自动停车；
4. 单程序限制：最多 300 块积木、嵌套 15 层、最长运行 600 秒；
5. 急停会同时停电机和终止程序。

### 6.5 保存与导出

- 程序自动保存在**浏览器 localStorage**，刷新不丢；
- 支持导出 JSON / 导入 JSON，方便交作业和换电脑；
- 换浏览器或清缓存会丢失，重要程序请导出备份。

## 七、学生 Python API

适合已经会写 Python 的同学，在自己的脚本里控制小车，不需要懂线程和硬件。

```python
import time
from petcar.student_api import EmojiRobot, Face, EyeStyle, MouthStyle

robot = EmojiRobot()

# 表情

    Face(left_eye=EyeStyle.HEART,

robot.nod()
```

3. 脚本结束前调用 `robot.stop()` / `robot.close()` 释放电机、摄像头和 OLED；

## 八、日常维护

| 项目 | 建议 |
|---|---|
| 电池 | 每次课后充电；长期不用保持 50% 左右 |
| 轮子 | 定期清理缠线、毛发；麦轮小辊子不能卡死 |
| 舵机 | 听到持续“嗡嗡”声说明到限位，立即回正 |
| 摄像头 | 用眼镜布擦镜头；不要用手指摸 |
| OLED | 避免长时间显示高亮静态画面，防止烧屏 |
| 树莓派 | 加散热片/风扇；温度 > 80°C 会降频 |
| 线缆 | 检查 I2C 杜邦线是否松动（表现为 OLED 花屏、电机乱转） |
| 固件 | 升级代码前先导出积木程序；`--push` 会清空板上 `petcar/`，但保留 `data/config_local.json` |

## 九、故障排查

### 9.1 打不开面板

| 可能原因 | 处理 |
|---|---|
| 程序没启动 | `python run_petcar.py --logs` 看报错 |
| 进程不在了 | `ssh pi@<IP> "pgrep -af petcar.main"` |
| IP 变了 | 板端 `hostname -I`，或路由器后台查看 |
| 不在同一网络 | 电脑和小车连同一 WiFi |
| 5000 端口被占 | `python run_petcar.py --stop` 后重启 |
| 浏览器缓存旧页面 | `Ctrl + F5` 强制刷新 |

### 9.2 电机 / 云台

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 四个轮子都不转 | 电池没电、驱动板没供电、I2C 没连上 | 充电；`i2cdetect -y 1` 查 `60` |
| 只有一个轮子转 | 电机线插错通道、电机坏 | 对照通道表重新插 |
| 方向相反 | 电机线正负极接反 | 对调该电机两根线 |
| 走不直 | 轮子打滑、地面不平、速度太低 | 提高速度；检查麦轮小辊子 |
| 云台不动 | 舵机线没插、角度已到限位 | 检查通道 0/1；点 ⊙ 回正 |
| 云台抖动/嗡嗡响 | 到达机械限位 | 立即回正，不要继续加角度 |
| OLED 花屏、电机乱转 | I2C 线松动或供电不足 | 重新插紧、换 5V/3A 电源 |

### 9.3 视频 / 识别

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 视频黑屏 | 摄像头被占用、USB 松动 | `ls /dev/video*`；重启程序 |
| 视频很卡 | 同时开了太多识别项 | 只保留 1~2 项 |
| 没有检测框 | 对应复选框没点亮、模型缺失 | 点亮复选框；看日志是否有模型报错 |
| 手势识别不可用 | 板卡不支持 MediaPipe，已自动回退 | 正常现象，看日志确认回退到 OpenCV |
| 颜色识别抓不到 | 光照变化、HSV 范围太窄 | 重新点预设色块或放宽 S/V |
| PID 追踪来回摆 | Kp 太大 | 把 Kp 降到 0.08~0.12 |

### 9.4 语音

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 完全没声音 | 输出走了 HDMI | `raspi-config` 切耳机/USB；或设 `PETCAR_TTS_DEVICE` |
| 声音很小 | 音量低 | `alsamixer` 调高 |
| 识别结果为空 | 麦克风选错、音量低、说话太轻 | 用「语音自检」看峰值；换 USB 麦克风 |
| 识别成乱码/不完整 | 环境吵、语速快、模型小 | 安静环境、放慢语速；换 `PETCAR_WHISPER_MODEL=small` |
| 小车自问自答 | 喇叭声音被麦克风拾取 | 降低音量；让麦克风远离喇叭；程序已做回声过滤 |
| 说完没反应 | 程序在快速模式（ASR=mock） | 用 `python run_petcar.py --full` 启动 |
| “跳舞”有回应但不跳 | 当前动作库没有注册 dance | 改用“转个圈”或面板「转圈」按钮 |

### 9.5 大模型

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 回复很慢 | 板端算力有限 | 换 `qwen2.5:0.5b`；降低生成长度 |
| 提示模型不可用 | Ollama 没启动/模型没拉 | `systemctl status ollama`；`ollama pull qwen2.5:0.5b` |
| 动作指令不执行 | 小模型不会调用工具 | 用固定指令；或换 `doubao` 后端 |
| 内存不足/系统卡 | 1.5B + Whisper + 视觉同时跑 | 换 0.5B；关掉不用的识别项 |
| 豆包报鉴权失败 | Key 错误/过期 | 面板设置里重新填 Key |

### 9.6 积木

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 点运行没反应 | 没有「当程序开始」、有多个起点 | 只保留一个事件积木 |
| 提示 409 | 已有程序在跑 | 先点停止/急停 |
| 程序跑一半停了 | 看门狗超时（页面断网/卡死） | 检查网络；重新运行 |
| 页面样式错乱 | Blockly 静态资源缺失 | 重新推送 `petcar/api/static/blocks/` |
| 导入 JSON 失败 | 版本不匹配/手改坏了 | 重新导出，不要手改 |

## 十、命令速查表

### 10.1 开发机（Windows）

```powershell
python run_petcar.py            # 启动
python run_petcar.py --restart  # 重启
python run_petcar.py --full     # 启动完整语音
python run_petcar.py --logs     # 看日志
python run_petcar.py --stop     # 停止
python run_petcar.py --push     # 推代码并启动
```

### 10.2 板端（Linux）

```bash
# 启动
setsid python3 -m petcar.main --flask --port 5000 \
  > ~/AITank/petcar/logs/petcar.log 2>&1 < /dev/null &

# 停止 / 查进程 / 看日志
pkill -f 'petcar.main'
pgrep -af petcar.main
tail -f ~/AITank/petcar/logs/petcar.log

# 硬件检查
i2cdetect -y 1
ls /dev/video*
arecord -l
aplay -l

# 服务检查
systemctl status ollama
curl http://localhost:11434/api/tags
```

### 10.3 常用环境变量

| 变量 | 作用 |
|---|---|
| `PETCAR_HOST` | 一键脚本连接的板子 IP |
| `PETCAR_LLM_BACKEND` | `ollama` / `doubao` / `mock` |
| `PETCAR_OLLAMA_HOST` | Ollama 地址，可指向局域网 PC |
| `PETCAR_OLLAMA_MODEL` | `qwen2.5:0.5b` / `qwen2.5:1.5b` |
| `PETCAR_ASR_MODE` | `whisper` / `mock` |
| `PETCAR_ASR_DEVICE` | 麦克风序号或名字片段 |
| `PETCAR_TTS_MODE` | `edge` / `piper` / `espeak` / `mock` |
| `PETCAR_TTS_DEVICE` | ALSA 播放设备 |
| `PETCAR_TTS_VOICE` | `zh-CN-XiaoyiNeural`（女童）/ `zh-CN-YunxiaNeural`（男童） |
| `PETCAR_TTS_PITCH` | 音调，默认 `+15Hz` |
| `PETCAR_WHISPER_MODEL` | `tiny` / `base` / `small` |
| `PYTHONUNBUFFERED` | 设为 `1`，后台日志不缓冲 |

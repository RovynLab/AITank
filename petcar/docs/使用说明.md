# AI-PetCar 使用说明（How to Use）

面向"把车跑起来 + 打开中控面板/积木编程"的日常使用，不涉及代码细节。设计细节见 [详细设计文档](./详细设计文档.md)、[积木编程引擎设计文档](./积木编程引擎设计文档.md)。

---

## 1. petcar 是怎么启动的

petcar 没有 systemd、没有 nginx，**一个 Python 进程就够了**。入口是 `python3 -m petcar.main`，默认启动完整链路（面板 + 语音）：

```
python3 -m petcar.main
```

只想开 Web 面板时用 `python3 -m petcar.main --flask --port 5000`（不跑语音循环）。

启动顺序（`petcar/main.py` → `_connect_all()`）：

1. **驱动层**：OLED、麦轮（PCA9685 电机 HAT）、二自由度云台、USB 摄像头、TTS、ASR
2. **核心层**：表情引擎、情绪引擎、技能管理器、LLM 后端、语音交互
3. **积木运行时**：`BlockRuntime` + `BlockService`（供 `/blocks` 页面调用）
4. **Flask**：在**后台线程**里跑 `app.run(host=0.0.0.0, port=5000)`
5. 主线程负责保活（`--flask` 模式下就是 `sleep` 循环），Ctrl+C 退出时统一释放电机、摄像头等资源

所以：

- 访问 `http://<板子IP>:5000/` 是中控面板，`/blocks` 是积木编程页
- **日志默认没有落盘**，一键脚本会重定向到 `~/AITank/petcar/logs/petcar.log`
- 同一时间只允许一个 petcar 进程（否则 5000 端口会被占用）

## 2. 一键启动（推荐）

在 Windows 开发机 `e:\work\AITank` 目录下：

**方式 A：双击**

```
run_petcar.bat
```

**方式 B：命令行**

```powershell
python run_petcar.py            # 启动（已在运行则直接提示地址）
python run_petcar.py --restart  # 重启
python run_petcar.py --push     # 先推最新代码，再启动
python run_petcar.py --full     # 完整语音链路（默认行为，whisper 用配置默认模型）
python run_petcar.py --logs     # 看最近 40 行日志
python run_petcar.py --stop     # 停止板上进程
```

启动成功后输出：

```
[OK] 已启动 → http://192.168.0.100:5000/
     积木编程 → http://192.168.0.100:5000/blocks
```

脚本做的事：SSH 连板子 → 杀掉旧的 `petcar.main` → `setsid` 后台启动 → 轮询 HTTP 确认真的起来了 → 打印访问地址（失败则自动打印日志尾部）。

### 参数说明

| 参数 | 作用 |
|---|---|
| `--port 5000` | 指定 Web 端口 |
| `--voice` | 开启麦克风语音对话（whisper base，自动录音，无需按 Enter） |
| `--offline` | 语音改用本地离线童声（piper），完全不依赖外网 |
| `--full` | 完整语音链路（whisper 使用配置默认模型）。不加参数时也是这个行为 |
| `--push` | 调用 `deploy_petcar.py push` 把本地 `petcar/` 整个推到板上（**会清空板上旧 petcar 目录**） |
| `--restart` | 先停再起 |
| `--stop` / `--logs` | 停止 / 查看日志 |

### 板子地址不是 192.168.0.100？

用环境变量覆盖，无需改代码：

```powershell
$env:PETCAR_HOST="192.168.0.101"
$env:PETCAR_SSH_USER="pi"
$env:PETCAR_SSH_PASS="raspberrypi"
python run_petcar.py --restart
```

或临时指定：`$env:PETCAR_HOST="192.168.0.101"; python run_petcar.py`

## 3. 手动启动（不用脚本）

SSH 到板子：

```bash
ssh pi@192.168.0.100          # 密码 raspberrypi

cd ~/AITank

# 只跑 Web（不跑语音循环；ASR 仍会加载 whisper）
setsid python3 -m petcar.main --flask --port 5000 \
  > ~/AITank/petcar/logs/petcar.log 2>&1 < /dev/null &

# Web + 语音对话（完整链路）
setsid python3 -m petcar.main --port 5000 \
  > ~/AITank/petcar/logs/petcar.log 2>&1 < /dev/null &

# 停止
pkill -f 'petcar.main'

# 看日志
tail -f ~/AITank/petcar/logs/petcar.log
```

`main.py` 其他用法：

```bash
python3 -m petcar.main                # Web + 语音交互都开
python3 -m petcar.main --flask        # 只开 Web 面板（不跑语音循环）
python3 -m petcar.main --voice        # 只开语音交互
python3 -m petcar.main --test-emotion # 轮播 12 种表情
```

> **只能在树莓派真机上运行**：当前版本已移除 mock 运行方式（`--mock`、`--rules`、`PETCAR_ASR_MODE=mock` 等均已删除）。OLED 或 whisper 初始化失败会直接报错，底盘/云台驱动缺失时会明确提示不可用，TTS 只在真实引擎之间降级。Windows 开发机只能做纯逻辑/接口测试，完整运行请在树莓派上。

## 4. 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PETCAR_LLM_BACKEND` | `ollama` | `ollama` / `doubao` |
| `PETCAR_OLLAMA_HOST` | `http://localhost:11434` | Ollama 服务地址 |
| `PETCAR_OLLAMA_MODEL` | `qwen2.5:0.5b` | Ollama 模型（2GB 内存板推荐 0.5b） |
| `PETCAR_DOUBAO_KEY` | 空 | 豆包 API Key |
| `PETCAR_ASR_DEVICE` | 空 | 麦克风（sounddevice 序号或名字片段）；留空自动探测 USB 麦克风 |
| `PETCAR_WHISPER_MODEL` | `small` | whisper 模型规格 |
| `PETCAR_TTS_MODE` | `edge` | 语音合成方式：`edge`（云端童声，断网自动降级 piper）/ `piper`（纯离线童声）/ `espeak` / `pyttsx3` |
| `PETCAR_TTS_DEVICE` | 空 | ALSA 播放设备（如 `plughw:CARD=UACDemoV10,DEV=0`）；留空自动探测 USB 声卡 |
| `PETCAR_TTS_VOICE` | `zh-CN-XiaoyiNeural` | edge 音色：女童声 `zh-CN-XiaoyiNeural`，男童声 `zh-CN-YunxiaNeural` |
| `PETCAR_TTS_PITCH` | `+15Hz` | edge 音调，调高更像小朋友 |
| `PETCAR_EDGE_TIMEOUT` | `10` | 云端合成超时（秒），超时立即改用离线 piper |
| `PETCAR_PIPER_BIN` | `/home/pi/piper/piper/piper` | 离线 TTS 可执行文件 |
| `PETCAR_PIPER_MODEL` | `/home/pi/piper/zh_CN-huayan-medium.onnx` | 离线中文模型 |
| `PETCAR_PIPER_PITCH` | `1.25` | 离线变调倍率，1.0 为原声（成年女声），越大越像小孩 |
| `PETCAR_WAKE_WORD` | `你好小强` | 语音唤醒词 |

**离线童声（Piper）**：板上文件位于 `/home/pi/piper/`（`piper/piper` 可执行 + `zh_CN-huayan-medium.onnx` + `zh_CN-huayan-medium.onnx.json`，约 136MB）。默认 `edge` 优先、断网 10 秒内自动降级到 piper（音调 x1.25 童声化），都失败才用 espeak。想完全离线：`python run_petcar.py --voice --offline`。

想用本地大模型：板上已装 ollama 服务（`systemctl status ollama`），模型 `ollama pull qwen2.5:0.5b`；启动时 `python run_petcar.py --voice` 即语音对话。

## 5. 打开中控面板 / 积木编程

| 页面 | 地址 | 说明 |
|---|---|---|
| 中控面板 | `http://192.168.0.100:5000/` | 视频流、方向控制、云台、云台角度、颜色识别、PID 追踪、技能按钮 |
| 积木编程 | `http://192.168.0.100:5000/blocks` | 左侧选积木拖拽拼装，右上运行/停止/急停 |

积木页要点：

- 程序是**浏览器编辑、车端解释执行**：点"运行"把整份积木 JSON 一次性发给板子，车端逐块执行，页面轮询状态并高亮当前积木
- 积木会自动保存在浏览器 localStorage，刷新不丢；支持导出/导入 JSON
- 运动类积木有 0.6s 运动租约 + 看门狗，页面卡死/断网会自动停车
- 运行期间，中控面板的手动运动/云台接口会返回 409（避免打架）
- 快捷键：`Ctrl+Enter` 运行，`Esc` 停止

## 6. 常见问题

**页面打不开**
1. `python run_petcar.py --logs` 看是否有报错
2. 确认进程在：`ssh pi@... "pgrep -af petcar.main"`
3. 确认在同一局域网，IP 用 `python run_petcar.py` 输出的地址

**启动即退出**
多半是驱动初始化失败（电机 HAT / I2C / 摄像头被占用）。日志里会出现 traceback，按提示检查硬件连接与 `i2cdetect -y 1`。

**提示端口被占用**
说明已有 petcar 在跑：`python run_petcar.py --stop` 后重新启动，或 `--restart`。

**改了前端（CSS/JS）但页面没变**
静态资源会被浏览器缓存，按 `Ctrl+F5` 强制刷新。也可以只推静态文件而不用整体重推。

**积木页图标/样式异常**
检查 `petcar/api/static/blocks/vendor/blockly/media/` 是否完整（Blockly 的 `sprites.png` 等二进制资源必须原样拷贝）。

**急停**
页面右上"急停"或 `curl -X POST http://192.168.0.100:5000/api/blocks/estop`，会立刻停电机并终止积木程序。
